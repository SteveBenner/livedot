# Security

Report a vulnerability privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

Include the livedot version, what you found, and how to reproduce it. You can expect an acknowledgement, and a fix or a decision, as soon as the maintainer can manage; livedot is maintained by one person.

livedot runs on your desktop as your user. It runs the commands your `config.yml` names, so treat that file as code you trust.
